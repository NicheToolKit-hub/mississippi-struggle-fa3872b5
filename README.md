# Mississippi Struggle

Act as an expert full-stack web developer and UI/UX designer. Build a modern, highly secure, and accessible website for the (Mississippi Struggle) Prison Reform Initiative. The site should feel urgent, professional, and community-focused, utilizing a trustworthy and serious color palette (e.g., deep navy, charcoal, muted gold/crimson accents) with clean typography.

Implement a fully responsive design (desktop and mobile) with smooth navigation. Create the following key pages and features:

### 1. Navigation & Layout

 * **Header:** Logo placeholder, organization name, and navigation links. Include a prominent, high-contrast **"Donate Now"** button.

 * **Footer:** Newsletter sign-up, social media links, disclosure/non-profit legal text, and contact info.

### 2. Home Page

 * **Hero Section:** A powerful headline focusing on justice and reform in Mississippi, a brief mission statement, and two primary Call-to-Action (CTA) buttons: "Sign the Petition" and "Get Involved."

 * **Impact Metrics:** A visual row of statistics (e.g., incarceration rates, lives impacted) using counters or clean cards.

 * **Latest News/Updates:** A grid section showcasing recent blog posts or press releases.

### 3. Donors & Fundraising Page

 * **Tiered Donation Cards:** Interactive cards for one-time or monthly donations (e.g., $25, $50, $100, Custom Amount).

 * **Donor Roll/Transparency:** A section listing top donors or corporate sponsors (with placeholders) and a pie chart or breakdown showing exactly how funds are allocated (e.g., legal defense, education, advocacy).

 * **Secure Payment Gateway UI:** Mock integration components for Stripe/PayPal processing.

### 4. Education & Law Page

 * **Resource Hub:** An educational repository explaining the current state of the Mississippi penal system.

 * **Know Your Rights:** An accordion-style FAQ or downloadable PDF section detailing legal rights for incarcerated individuals and their families.

 * **Infographics:** Visual layouts detailing the school-to-prison pipeline or recidivism statistics.

### 5. Proposed Bills & Laws Page

 * **Legislation Tracker:** A searchable, filterable table or list of active, proposed, or passed bills in the Mississippi Legislature.

 * **Bill Status Component:** Each bill should have a visual progress bar (e.g., Introduced -> Committee -> Voting -> Signed).

 * **"Take Action" Link:** Every bill should have a quick link directing users to contact their local representative regarding that specific bill.

### 6. Signatures & Petitions Page

 * **Active Petitions:** A formal petition layout detailing a current reform demand.

 * **Signature Form:** A clean input form capturing Full Name, Email, Address/Zip Code (to verify Mississippi residency), and an optional comment box.

### Technical Requirements:

 * Use clean, semantic HTML5, modern CSS (Tailwind CSS preferred), and robust JavaScript for interactivity.

 * Ensure strict accessibility standards (WCAG 2.1 AA compliance) with high text contrast and aria-labels.

 * Write modular, well-commented code so components can be easily integrated with a backend database (like Supabase or Firebase) later.
